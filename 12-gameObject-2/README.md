## 연산자와 조건문

### 1. 관계 연산자

- 두 피연산자 사이의 관계를 확인하는 연산자
- 관계 연산자를 기준으로 왼쪽과 오른쪽의 관계를 비교
- 관계 연산자는 `true` 또는 `false`를 리턴
- 연산자의 비교가 옳으면 `true`, 옳지 않으면 `false`를 리턴
- 관계 연산자의 종류는 `<`, `>`, `<=`, `>=`, `==`, `!=`이다.

### 2. 논리 연산자

- 논리 연산자를 기준으로 양쪽의 관계가 참인지, 거짓인지와 부정을 연산
- `true` 또는 `false`를 리턴
- 논리 연산자의 종류는 `&&`, `||`, `!`이다.

### 3. 조건 연산자

- `?:`
- 피연산자가 3개인 연산
- 조건이 참일 때의 값과 거짓일 때의 값을 구분해서 리턴

### 4. if ~ else if ~ else

- 조건식을 만족하는 코드 블럭을 실행
- `if`문의 조건식을 만족하지 않을 경우 `else if` 또는 `else` 구문을 확인
- 모든 조건식을 만족하지 않을 경우 `else` 구문을 실행

    ```csharp
    if(조건식)
    {
        코드 블럭
    }
    else if(조건식)
    {
        코드 블럭
    }
    else
    {
        코드 블럭
    }
    ```
