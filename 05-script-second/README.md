## 변수

1. **변수**
   - 데이터를 저장하는 메모리 공간을 의미한다.
   - **값 형식의 변수**와 **참조 타입의 변수**로 구분할 수 있다.

2. **정수형 변수 데이터타입**
   - `sbyte`
   - `short`
   - `int`
   - `long`
   - `byte`
   - `ushort`
   - `uint`
   - `ulong`

3. **실수형 변수 데이터타입**
   - `float`
   - `double`

4. **열거형 변수**
   - 숫자값에 이름을 부여해서 사용하는 용도로 `enum`을 사용한다.

5. **구조체형 변수**
   - 클래스와 형식이 유사한 타입으로 `struct`를 사용한다.

6. **참조형식의 변수**
   - 클래스 형식
   - 인터페이스 형식
   - 배열 형식
   - 대리자 형식
   - 문자열 형식

7. **지역변수와 전역변수**
   - 지역변수는 해당 코드블럭 안에서만 유효한 변수를 의미한다.
   - 전역변수는 해당 프로그램 안에서 유효한 변수를 의미한다.

8. **상수**
   - 변수 선언 앞에 `const` 키워드를 붙여 사용한다.
   - 선언과 동시에 초기화되어야 한다.
   - 선언 이후에는 값을 변경할 수 없다.
