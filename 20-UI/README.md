# Unity UI 시스템

## 1. Canvas 설정

`Canvas`는 Unity에서 **UI를 표시하기 위한 영역**이다.

Canvas의 `Render Mode`를 통해 UI가 화면에 표시되는 방식을 설정할 수 있다.

### 1) Screen Space - Overlay

화면 위에 UI를 직접 표시하는 방식이다.

* UI가 카메라와 관계없이 화면에 표시된다.
* 화면의 크기나 해상도가 변경되면 UI가 화면에 맞게 자동으로 조정된다.
* 일반적인 게임의 HUD, 메뉴 등에 사용할 수 있다.

```text
Screen
┌─────────────────────────┐
│                         │
│       UI Canvas         │
│                         │
└─────────────────────────┘
```

---

### 2) Screen Space - Camera

Canvas를 특정 카메라에 연결하여 UI를 표시하는 방식이다.

* UI가 지정된 카메라를 기준으로 화면에 표시된다.
* 화면의 크기나 해상도에 따라 UI가 자동으로 조정된다.
* 카메라의 위치나 절두체(Fustum) 설정의 영향을 받을 수 있다.

```text
Camera
   ↓
Canvas
   ↓
UI
```

---

### 3) World Space

Canvas를 **게임 월드 공간에 존재하는 일반적인 오브젝트처럼 배치**하는 방식이다.

* UI가 게임 월드의 좌표를 가진다.
* Canvas의 위치, 회전, 크기를 자유롭게 설정할 수 있다.
* 카메라를 향하도록 설정하지 않아도 된다.
* 게임 공간에 존재하는 UI를 구현할 때 사용할 수 있다.

예시:

* NPC 머리 위 이름표
* 체력바
* 월드에 배치된 안내판
* 3D 공간의 UI

---

## 2. RectTransform

`RectTransform`은 **UI 오브젝트 전용 Transform**이다.

일반적인 `Transform`의 기능에 더해 UI 배치에 필요한 정보를 포함한다.

주요 정보:

* 위치(Position)
* 회전(Rotation)
* 크기(Size)
* 스케일(Scale)
* 앵커(Anchor)
* 피벗(Pivot)

```text
RectTransform
├── Position
├── Rotation
├── Scale
├── Size
├── Anchor
└── Pivot
```

---

## 3. UI 구현

Unity에서는 다양한 UI Component를 사용하여 UI를 구성할 수 있다.

### 1) Text Component

UI 화면에 **문자를 출력하는 컴포넌트**이다.

```text
Text
└── "Hello World"
```

---

### 2) Outline Component

Text 등의 UI 요소에 **외곽선(Outline)을 추가**하는 컴포넌트이다.

```text
┌─────────────┐
│   TEXT      │ ← 외곽선
└─────────────┘
```

---

### 3) Button Component

사용자가 버튼을 클릭했을 때 발생하는 **버튼 이벤트를 처리**하는 컴포넌트이다.

예시:

```text
[   START   ]
      ↓
   클릭 이벤트
      ↓
게임 시작
```

---

### 4) Image Component

UI 화면에 **이미지를 출력하는 컴포넌트**이다.

* 아이콘
* 배경 이미지
* 버튼 이미지
* 캐릭터 이미지
* 게이지 등

---

## 4. Image Component의 Image Type

`Image` 컴포넌트의 `Image Type`을 사용하여 이미지가 UI 영역에 표시되는 방식을 설정할 수 있다.

### 1) Simple

원본 이미지를 전체 영역에 표시한다.

```text
┌──────────────┐
│              │
│    Image     │
│              │
└──────────────┘
```

---

### 2) Sliced

**9-Slicing(9-Slice)** 기술을 사용하여 이미지의 모서리는 유지하면서 가운데 영역을 늘려 UI 크기에 맞게 표시한다.

하나의 이미지를 여러 크기의 UI에서 재사용할 수 있다.

```text
┌───┬────────┬───┐
│ 1 │   2    │ 3 │
├───┼────────┼───┤
│ 4 │   5    │ 6 │
├───┼────────┼───┤
│ 7 │   8    │ 9 │
└───┴────────┴───┘
```

* 모서리 부분 → 크기를 유지
* 가운데 부분 → 크기에 맞게 늘어남

주로 **UI 패널, 버튼, 창 등의 배경**에 사용한다.

---

### 3) Tiled

원본 이미지를 **반복해서 배치하여 지정된 영역을 채우는 방식**이다.

```text
┌──────────────┐
│ ▦ ▦ ▦ ▦ ▦ ▦ │
│ ▦ ▦ ▦ ▦ ▦ ▦ │
│ ▦ ▦ ▦ ▦ ▦ ▦ │
└──────────────┘
```

이미지를 단순히 늘리는 것이 아니라 **타일처럼 반복**하여 영역을 채운다.

---

### 4) Filled

이미지의 **일부 영역만 표시하는 방식**이다.

`Fill Amount` 값을 이용하여 표시되는 이미지의 양을 조절할 수 있다.

```text
Fill Amount = 0.25

┌──────────────┐
│████          │
│████          │
│████          │
└──────────────┘
```

주로 다음과 같은 UI에 사용할 수 있다.

* 체력 게이지
* 스킬 쿨타임
* 경험치 게이지
* 진행률 표시

---

## 5. Scroll View

`Scroll View`는 **많은 양의 UI 내용을 스크롤하여 확인할 수 있도록 만드는 UI**이다.

예시:

* 인벤토리
* 아이템 목록
* 채팅창
* 설정 메뉴
* 랭킹 목록

Scroll View는 일반적으로 다음과 같은 구조로 구성된다.

```text
Scroll View
├── Viewport
│   └── Content
└── Scrollbar
```

### 1) ScrollRect

`ScrollRect`는 **Scroll View의 스크롤 동작과 속성을 관리**하는 컴포넌트이다.

* 가로 스크롤
* 세로 스크롤
* 스크롤 위치
* 스크롤 감도 등을 설정할 수 있다.

---

### 2) Viewport

실제로 **화면에 표시되는 영역**이다.

Viewport의 영역을 벗어난 Content는 화면에 표시되지 않는다.

```text
Content
┌────────────────────────────┐
│                            │
│   ┌────────────────────┐   │
│   │     Viewport       │   │
│   │                    │   │
│   │    표시되는 영역    │   │
│   │                    │   │
│   └────────────────────┘   │
│                            │
└────────────────────────────┘
```

---

### 3) Content

실제로 **스크롤되는 UI 내용이 배치되는 영역**이다.

예를 들어 아이템 목록을 만든다면 각각의 아이템 UI를 `Content`의 자식으로 추가한다.

```text
Scroll View
└── Viewport
    └── Content
        ├── Item 1
        ├── Item 2
        ├── Item 3
        ├── Item 4
        └── Item 5
```

Content의 크기가 Viewport보다 커지면 스크롤을 통해 보이지 않는 영역까지 확인할 수 있다.
