1. **클래스**는 연관성 있는 데이터와 기능을 하나로 묶어서 정의하는 프로그래밍 규칙을 의미한다.

2. **접근 한정자**로 주로 사용되는 세 가지는 `public`, `private`, `protected`가 있다.

3. **코드 블록**은 클래스나 함수의 시작과 끝을 나타내는 문법으로, `{`는 코드 블록의 시작을 의미하고 `}`는 코드 블록의 끝을 의미한다.

4. `MonoBehaviour`를 상속받는 클래스는 **컴포넌트로 사용할 수 있다.**

5. **컴파일**은 프로그래밍 언어로 작성된 코드를 기계어 또는 실행 가능한 형태로 변환하는 것을 의미하고, **빌드**는 컴파일 등의 과정을 거쳐 최종적으로 실행 가능한 프로그램이나 파일을 생성하는 것을 의미한다.
