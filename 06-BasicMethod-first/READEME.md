## 메소드와 알고리즘

### 1. 메소드

- 객체지향 언어에서 사용하는 함수와 같은 용어이다.
- 일련의 코드를 하나의 코드로 묶은 것을 의미한다.
- 주로 특정 기능을 구현하기 위한 용도로 사용된다.

### 2. 알고리즘

- 어떠한 문제를 해결하기 위한 논리를 프로그램의 문법을 사용하여 정의해 놓은 것을 의미한다.
- Unity에서는 일반적으로 한 개 이상의 클래스를 사용하여 작성한다.

### 3. Unity 이벤트 메소드

| 메소드 | 설명 |
| --- | --- |
| `Awake` | 클래스의 인스턴스가 생성될 때 호출 |
| `Start` | 렌더링 되기 바로 직전에 호출 |
| `OnEnable` | 게임 오브젝트가 활성화될 때 호출 |
| `OnDisable` | 게임 오브젝트가 비활성화될 때 호출 |
| `Update` | 매 프레임마다 주기적으로 호출 |

### 4. 메소드의 리턴타입

- 메소드의 리턴타입은 메소드 밖으로 반환되는 데이터 타입에 의해 결정된다.
- 리턴타입이 `void`라는 것은 반환할 데이터가 없다는 의미이다.
- `void` 메소드에서는 `return`을 생략해도 된다.

### 5. 오버로드와 오버라이드

#### 오버로드

- 이름은 같지만 매개변수가 다른 메소드를 정의하는 것이다.

#### 오버라이드

- 부모 클래스의 메소드를 자식 클래스에서 재정의하여 사용하는 것이다.
- 부모 클래스에서는 `virtual` 키워드를 사용한다.
- 자식 클래스에서는 `override` 키워드를 사용한다.
